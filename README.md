# Kattire – Karen Traditional Attire Website

Kattire is a web-based platform designed to **promote Karen traditional attire, culture, and handmade products** while providing a simple online shopping experience.

## Features

* User registration & login
* Browse and view products
* Shopping cart
* Order & checkout
* Payment management
* Product reviews
* Admin dashboard
* Product, order, and user management

## Technologies

* HTML
* CSS
* JavaScript
* PHP
* MySQL
* Git & GitHub

## Database

The system uses a relational database with tables for:

* Users
* Categories
* Products
* Shopping Cart
* Orders
* Payments
* Reviews

## Purpose

This project was developed as an academic project to combine **web development, database management, e-commerce, and Karen cultural promotion**.

## Team Project

Developed as a group project for educational purposes.
